BrownEye MTG Arbitrage Dashboard

Closed-loop arbitrage pipeline with seed ingestion, scoring, Discord alerts, and feedback tuning. All artifacts land in the BrownEye Cortex data lake.

Pipeline

  • Seeds: JSON jobs dropped into C:\BrownEyeCortex\Queue\.
  • Ingestion: SeedBot normalizes card SKUs, marketplaces, and fee assumptions.
  • Scoring: ScoreBot applies margin, liquidity, velocity, risk weights from Arbitrage_Scoring_Config.json.
  • Alerts: AlertBot posts qualified hits to Discord with normalized FX and fee load.
  • Feedback: LearnBot reviews realized P&L and adjusts weights automatically.

Bots and Roles

  • SeedBot: queue seeding and validation.
  • CollectBot: scrape or import market snapshots.
  • ScoreBot: compute normalized scores and priority.
  • AlertBot: send Discord alerts and append CSV output.
  • LearnBot: tune scoring weights based on historical performance.
  • BuildBot: artifact generation for primers and funerals.

Data Lake Layout

  • C:\BrownEyeCortex\Data\Lake\Arbitrage\
  • C:\BrownEyeCortex\Data\Lake\Primers\
  • C:\BrownEyeCortex\Data\Lake\DeckFunerals\
  • C:\BrownEyeCortex\Data\Lake\Kelphaven\
  • C:\BrownEyeCortex\Data\Lake\System\

Operational Checklist

  • Run the mega bootstrap: powershell -ExecutionPolicy Bypass -File C:\BrownEyeCortex\Bootstraps\BrownEye_Factory_MegaBootstrap.ps1.
  • Confirm queue folder exists and is writable.
  • Set $env:DISCORD_WEBHOOK_URL before enabling alerts.
  • Ensure Scheduled Tasks are enabled for SeedBot and ScoreBot cadences.
  • Review C:\BrownEyeCortex\Logs\Arbitrage\ for run health and tuning notes.

Minimum Viable Scripts

  • Seed injector drops JSON into queue with card, set, marketplace, thresholds.
  • Queue runner locks each job, computes normalized margin via FX/fee normalizer.
  • Scoring engine weights margin, velocity, liquidity, and risk into a single score.
  • AlertBot posts Markdown-friendly summary to Discord and appends CSV to Arbitrage_Results.csv.
  • LearnBot updates weights daily using realized profit signals in the data lake.
