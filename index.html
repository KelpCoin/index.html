  • NO_PRICES_IN_DM: “all pricing in bio.”

I) Conversion Rules (Anti-Spam + Human Feel)

  • Rotation: Use 4 reply buckets (sweet, playful, firm, safety) and rotate every 3 comments.
  • Cooldown: Max 2 CTA stories per day per account; 1 CTA per post caption.
  • Don’t get banned: avoid “explicit,” “pay for X,” “DM for prices,” “send cash for pics.”

J) Metrics Dash (Simple)

  • Daily numbers: profile visits, link clicks (or linktree views), paid conversions (tips + members).
  • Success thresholds: 5% profile → link click; 3% link click → conversion.
  • If missed: simplify hub copy, add one story CTA, re-pin intro post.
