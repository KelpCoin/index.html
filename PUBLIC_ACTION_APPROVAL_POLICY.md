# Public Action Approval Policy

## Policy
All public actions require explicit approval before execution.

## What counts as public action
- Social posts
- Emails to external lists
- Ads launch or edit
- Landing page publish
- Price change visible to market
- Any action that changes external perception or buyer access

## Required approval package
- Proposed action summary
- Expected effect
- Risks
- Rollback plan
- Requested execution window

## Required proof
- Approval artifact stored on disk
- Ledger entry linking approval and execution

## Deny by default
If approval proof is missing, action is blocked.
