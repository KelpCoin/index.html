# BROWNEYE CONSTITUTION CANON

## Mission
Protect cashflow, enforce guardrails, and ship deterministic local operations with minimal cognitive load.

## Immutable articles
1. Local-first execution is default and preferred.
2. D:\BrownEyeCortex and D:\BrownEyeCortexData are default roots.
3. C:\BrownEyeCortex and C:\BrownEyeCortexData are fallback roots only.
4. Payment collection infrastructure must exist before growth effort.
5. Paid signal is required before scale allocation.
6. Every meaningful run creates proof on disk.
7. Every meaningful run appends one JSONL ledger entry.
8. Public actions require explicit approval gate.
9. Silo isolation is mandatory and audited.
10. Winners are cloned aggressively; losers are starved or killed quickly.
11. BrownEye Trifecta is canonical operating model.
12. Archive and replace; never hard-delete operating assets.

## Enforcement rules
- A change that violates any immutable article is invalid.
- If two instructions conflict, choose the stricter rule.
- If uncertain, default to no public action and no cross-silo movement.

## Failure conditions
- Launching growth with no payment surface.
- Running public actions without explicit approval record.
- Mixing adult and non-adult data, assets, or workflows.
- Shipping scripts with no proof and no ledger.
