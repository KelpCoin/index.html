Recommended stack: Airtable

MTG Singles System: ManaBox → Airtable → Public Price List

This setup is optimized for your workflow: scan in ManaBox, export CSV/text with scryfall_id, import to Airtable, fetch near-live USD prices from Scryfall, convert to NZD, and calculate your offer price (e.g. 20% off converted NZD).

1) Table schema (create in Airtable)

Input fieldsName, Set, Collector #, Finish, Quantity, Scryfall ID
Fetched fieldsUSD Price, USD→NZD Rate, NZD Market
Business fieldsDiscount %, Your Offer NZD, Last Updated
  • Set Scryfall ID as single line text (required from ManaBox export).
  • Set Quantity as number.
  • Set Discount % default to 0.20.

2) Import from ManaBox

  1. In ManaBox, export your collection as CSV.
  2. Confirm the export includes scryfall_id (or equivalent unique Scryfall UUID column).
  3. In Airtable, use CSV import extension and map to your fields.

3) Automation script (Airtable scripting extension)

Paste the script from airtable_price_refresh.js in this repo. It will:

  • Pull USD card prices by scryfall_id from Scryfall API.
  • Pull live USD→NZD FX rate.
  • Update USD, NZD market, offer NZD, and timestamp.

Run every 15–30 minutes with Airtable Automation for near-live updates.

4) Pricing formula used

NZD Market = USD Price × USDNZD
Your Offer NZD = NZD Market × (1 - Discount %)

If Discount % = 0.20, buyers see a 20% lower price than converted NZD market.

5) Public storefront view

  • Create an Airtable Interface filtered to Quantity > 0.
  • Show card name, finish, quantity, NZD offer, NZD market, and last update time.
  • Share as read-only public link for buyers.

6) Deck-building (later phase)

Keep this as phase 2: export your owned singles from Airtable and run a recommendation script that scores deck archetypes by card coverage. Your table already has the key ID needed for this.

Tip: do not wait on deck-building to launch sales. Start with price + inventory visibility first.

APIs used

  • Scryfall card endpoint: https://api.scryfall.com/cards/{id}
  • FX endpoint: https://open.er-api.com/v6/latest/USD

Both are free endpoints suitable for frequent refreshes with a modest delay.
