Automation checklist

Ingestion

Scheduled pulls (cron/Task Scheduler) with retry + backoff; tag each run with seed ID and timestamp.

  • Normalize currencies (USD/EUR/GBP) and fees
  • Cache last price window to detect fresh spikes
  • Flag illiquid cards with volume < X per week

Scoring engine

Weighted score: margin (40%) + liquidity (30%) + velocity (20%) + risk (10%).

  • Auto-drop if photos missing and condition = unknown
  • Prefer playsets; penalize singletons with low volume
  • Surface floor/ceiling spreads for Discord preview

Webhook payloads

Send compact JSON to Discord:

  • Title: [Spread%] Card @ Source → Target
  • Fields: buy price, sell price, fees, net, velocity
  • Links: source listing, target draft listing

Feedback & tuning

Append realized profit per lot and seed ID; retrain weights weekly. Expire stale seeds automatically.

  • Drop SKUs with repeated failed flips
  • Boost seeds that hit >X profit/turnover
  • Archive metrics to CSV/Sheets for audit
Minimum viable scripts

PowerShell seed injector

Maintain manual control over targeting while automating ingestion.

  • Invoke-RestMethod to push seed JSON into the pipeline
  • Include set code, SKU list, region, min margin, max buy price
  • Trigger Windows Task Scheduler to kick collectors

Python collector

Requests/HTTPX fetchers with simple adapters per marketplace.

  • Persist to SQLite/Parquet for quick diffing
  • Compute spread + fees → score → filter
  • Send Discord webhook via requests.post

Discord notifier

Markdown cards per hit to keep the team aligned.

  • Embed: title, thumbnail (card art), buttons
  • Color-code by margin tier
  • Auto-thread by seed ID for discussion
