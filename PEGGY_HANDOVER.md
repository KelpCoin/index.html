# Peggy Handover

## Role
Peggy supports operations without violating guardrails or silo boundaries.

## Safe support actions
1. Run Verify_PhaseoutPack.ps1 and report status.
2. Check that logs, proofs, and ledgers were written.
3. Prepare approval package drafts for review.
4. Archive superseded files using archive/replace rule.
5. Compile daily checklist completion report.

## Actions Peggy must not do without explicit approval
- Any public posting or external publishing
- Any live pricing change
- Any campaign launch
- Any cross-silo data movement

## Escalation triggers
- Missing payment surface
- Missing proof artifacts
- Ledger write failure
- Any suspected silo breach

## Handover checklist
- Confirm root path selection
- Confirm verifier success
- Confirm latest ledger entry exists
- Confirm no blocked risk unresolved
